# Kukljica EcoOasis

Ecosystem restoration site, 7,02 ha, island of Ugljan, Croatia.
Bačina uvala, below the Čelinjak ridge.
Cadastral parcels 2448/6, 2448/14, 2448/13, 2449/1.

Live site: https://markoboskoauroville.github.io/KUKLJICA_ECOOASIS/

Single file build. All copy, styling and the EN/HR dictionary live in `index.html`.
Language switches with no reload, `?lang=hr` forces Croatian.

## Three crops app
`tri/` is a separate page linked from Growing food: choose a cereal, a pulse and an oil on a
Köppen-Geiger climate map. Crop data in `tri/crops.js`; the map data `tri/kg.js` is generated by
`tools/build_kg.py` (sources listed in its header).
