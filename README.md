# Kukljica EcoOasis

Ecosystem restoration site, 7,02 ha, island of Ugljan, Croatia.
Bačina uvala, below the Čelinjak ridge.
Cadastral parcels 2448/6, 2448/14, 2448/13, 2449/1.

Live site: https://markoboskoauroville.github.io/KUKLJICA_ECOOASIS/

Single file build. All copy, styling and the EN/HR dictionary live in `index.html`.
Language switches with no reload, `?lang=hr` forces Croatian.

## Credits
Photographs and drawings by Marko Boško unless otherwise credited.

## Three crops app
`tri/` is a separate page linked from Growing food: choose a cereal, a pulse and an oil on a
Köppen-Geiger climate map. Crop data in `tri/crops.js`; the map data `tri/kg.js` is generated by
`tools/build_kg.py` (sources listed in its header).

## Owner's manual
Section `#owners` in `index.html`: who holds each parcel of the project, a map coloured by family, by
number of sellers or by land-register status, rankings by possession sheet, person and family, parcel
sizes, a purchase plan, the land-register folios set against the cadastre, and a searchable register
with CSV download.

Data, refreshed in two steps from the repo root:

1. `python3 tools/fetch_oss.py` reads the current possession sheets and land-register folios of every
   project parcel from oss.uredjenazemlja.hr (the calls the ARKOD Layer app makes, see
   `markoboskoauroville/arkod_web`). Raw answers and the lawyer's detail (addresses, fathers' and maiden
   names) go to `.secret/`, which is git-ignored and never published; `data/oss.json` keeps names,
   shares, folio numbers and the country of holders abroad. Delete `.secret/oss/` to fetch afresh.
2. `python3 tools/build_owners.py` joins that with the DGU geometry in `.build/karta.html` and writes
   the data line between the `OWNERS-DATA` markers in `index.html`.
