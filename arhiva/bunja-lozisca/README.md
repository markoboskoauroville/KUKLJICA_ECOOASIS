# Bunja kod Ložišća, Brač — referentni arhiv

**PRIVATNO. Ne objavljuje se.**

Bunja koju je dizajnerica Ana Reić obnovila u svom masliniku kod Ložišća na Braču.
Zidovi 80 cm, oko 20 m² unutra, svaki kamen ručno klesan, krov od kamenih ploča,
tri godine gradnje. Najbolji poznati izvedeni primjer gradnje po starinski, i
referenca za ono što namjeravamo graditi u Bačinoj uvali.
